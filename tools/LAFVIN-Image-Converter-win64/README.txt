LAFVIN Four-Color Image Converter 1.0.0 - Windows x64

No Python or library installation is required.
1. Extract this ZIP to a folder.
2. Double-click LAFVIN-Image-Converter.exe.
3. Select 2.9-inch or 1.54-inch and the desired image rotation.
4. Drop an image onto the window to export BMP, C and H files.

A blank output folder creates a converted folder beside your input image.
Turn off automatic export to preview before saving.
Image rotation affects the preview and both outputs. For prepared four-color
artwork, use pixel-art resizing, sharpening 0 and dithering off.
The outputs match the current Raspberry Pi demos' 90-degree orientation.

中文说明：
本工具为 Windows 64 位免安装版本，无需安装 Python 或任何依赖库。
解压后双击 EXE，选择屏幕型号与图片旋转方向，再拖入图片即可导出。
导出文件包括 24 位 BMP、C 数组和 H 声明文件。
未指定输出目录时，会保存到原图旁边的 converted 文件夹。
关闭自动导出后可以先查看预览，再点击 Export 保存。
已准备好的四色图片建议使用像素缩放、锐化 0、关闭抖动。
本工具支持 2.9 寸与 1.54 寸黑白黄红四色墨水屏。
